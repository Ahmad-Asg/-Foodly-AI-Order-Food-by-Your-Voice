# Foodly AI - Order Food by Your Voice
Foodly AI is a voice-based food ordering app that lets users search for food, explore available items, and place orders using simple voice commands. It makes the food ordering experience faster, easier, and more interactive with AI powered voice assistance.

## Database foundation (Phase 4)

The MongoDB/Mongoose database foundation is in [`backend/`](backend/). It models one fictional restaurant, **Foodly AI Restaurant**, its menu, and the supporting user, cart, order, review, favorite, and AI conversation data.

See [`backend/README.md`](backend/README.md) for MongoDB Atlas setup and the seed command. No backend API or authentication has been added in this phase.
